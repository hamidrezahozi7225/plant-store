# TypeScript and Zod Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the existing dependency-only Express folder into a minimal TypeScript server with a working Zod request-validation example.

**Architecture:** Keep the starter intentionally small: one strict TypeScript configuration and one application entry point. Express owns HTTP transport, while a Zod schema at the route boundary converts untrusted request data into typed application data before it is returned.

**Tech Stack:** Node.js 24, npm 11, Express 5, TypeScript, tsx, Zod

**Spec:** `docs/superpowers/specs/2026-09-23-typescript-zod-setup-design.md`

## Global Constraints

- Preserve the existing Express, Mongoose, JWT, and bcrypt dependencies.
- Do not add authentication, database connectivity, CRUD features, or a route/controller/service hierarchy.
- Use `tsx` watch mode for development and `tsc` for type-checking and production builds.
- Treat Zod as a runtime dependency and TypeScript tooling/type declarations as development dependencies.
- Compile `src` into `dist`, and do not commit `dist` or `node_modules`.
- Do not add a test framework; verify the starter through the compiler and direct HTTP requests.

## Review Focus

- A request with an empty object must return HTTP 400 with validation issues.
- A numeric string such as `"12"` must not be silently accepted as a number.
- A whitespace-only plant name must return HTTP 400.
- A negative price must return HTTP 400.
- A valid request containing an unknown property must succeed while the unknown property is excluded from parsed output.

- [ ] **Step 7: Implement the minimal Express and Zod example**

Create `src/index.ts`:

```typescript
import express from "express";
import { z } from "zod";

const app = express();

app.use(express.json());

const plantSchema = z.object({
  name: z.string().trim().min(1, "Name is required"),
  price: z.number().nonnegative("Price cannot be negative"),
});

app.get("/health", (_request, response) => {
  response.status(200).json({ status: "ok" });
});

app.post("/plants/validate", (request, response) => {
  const result = plantSchema.safeParse(request.body);

  if (!result.success) {
    response.status(400).json({
      message: "Invalid request body",
      issues: result.error.issues,
    });
    return;
  }

  response.status(200).json({
    message: "Valid plant data",
    data: result.data,
  });
});

const port = Number(process.env.PORT ?? 3000);

app.listen(port, () => {
  console.log(`Server is running on http://localhost:${port}`);
});
```
